# Resoluções das provas

Um PDF por cadeira, em `pdf/`. Fórmulas em KaTeX (mesmo tipo de letra do ChatGPT); cada exercício tem o significado dos símbolos.

| PDF | Cadeira |
|---|---|
| `01_Fisico-Quimica_Exame-Epoca-Normal.pdf` | Físico-Química |
| `02_Fisica-Geral-II_Prova-Parcelar-e-Consolidacao.pdf` | Física Geral II (+ Prova de Consolidação II: Ondas Mecânicas) |
| `03_Estatistica-Basica_Prova-Parcelar.pdf` | Estatística Básica |
| `04_Calculo-Diferencial-e-Integral-III_Prova-Parcelar.pdf` | Cálculo Diferencial e Integral III |
| `05_Quimica-Organica_1a-Prova-Parcelar.pdf` | Química Orgânica |
| `06_English-III_1a-Prova-Parcelar.pdf` | English III |
| `07_Computacao-Cientifica-II_Ficha-de-Trabalho.pdf` | Computação Científica II |

`codigo-C/` tem os programas da ficha de Computação Científica II (testados).

Para regenerar: `cd src && npm install && npm run build` (precisa de Python 3, Node e Playwright/Chromium).
